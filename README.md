# Odin Recipes

This is a project that demonstrates HTML skills for [The Odin Project](https://www.theodinproject.com/) website.
Here is the [web page with instructions on how to build this project](https://www.theodinproject.com/lessons/foundations-recipes).

In this project, I will build a recipe site to demonstrate the following HTML skills:

- website structure
- headings
- ordered and unordered lists
- links
- images

The project consists of a main `index.html` page, recipe pages, images, and links.
